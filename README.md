# Studio Luana Rodrigues — site

Site institucional (one page) do Studio Luana Rodrigues, salão de beleza no Centro de Campinas — SP.

## Estrutura

- `index.html` — página completa
- `style.css` — estilos
- `script.js` — menu mobile, animações e galeria
- `assets/img/` — imagens

## Rodar localmente

Abra `index.html` no navegador ou use um servidor estático:

```bash
npx serve .
```

## Publicar

1. Crie um repositório **privado** no GitHub.
2. Envie o conteúdo desta pasta (o `index.html` deve ficar na raiz do repositório).
3. Na Vercel: **Add New → Project → Import Git Repository**, selecione o repositório.
4. Framework Preset: **Other**. Build Command: vazio. Output Directory: vazio.
5. Deploy. A URL gerada (ex.: `studio-luana.vercel.app`) já pode ser enviada para a cliente.

## Observação sobre as imagens

As fotos em `assets/img/` são do portfólio público do studio e estão aqui apenas
para demonstração. Antes de publicar oficialmente, substitua pelas fotos
fornecidas e autorizadas pela proprietária (e com autorização de imagem das clientes).
